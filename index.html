Ready to play?

For the official game, download the Minecraft Launcher from minecraft.net. Sign in with the Microsoft account that owns the game, choose an edition, and select Play.

The official launcher is the supported route for installing and updating Minecraft.

About third-party launchers

TLauncher is a third-party Minecraft launcher with version and mod-related features. It is separate from Mojang and Microsoft’s official launcher. Only download software from sources you trust, and use the official launcher for the straightforward supported route.

If you want to learn more, visit TLauncher’s website. Review its installer carefully before installing.
